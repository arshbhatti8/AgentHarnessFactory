# Skill: Generate Code

## Objective
Your goal as the Software Engineer is to write production-ready code based entirely on the PM's specification and **automatically proceed** to the QA phase.

## Rules of Engagement
- **Strict Compliance**: You must write code exclusively using the tech stack and architectural constraints outlined in the Technical Specification.
- **Save Location**: Modify and save all your code directly inside the appropriate project directories according to standard conventions for the chosen language/framework.
- **Integration**: Ensure all new components, modules, or services are properly wired and exported into the main application logic.
- **Continuous Execution**: Do NOT pause or ask for permission. Once the code is written and integrated, you must immediately hand off execution to the QA Engineer.

## Instructions
1. **Read the Spec**: Open and carefully study `docs/Technical_Specification.md`.
2. **Scaffold & Integrate**: Generate all core application files required by the specification. Integrate components into the main layout and logic flow. 
3. **Output Code**: Save your modifications natively in the workspace. Ensure all dependencies are accurately recorded in the appropriate package manager files (e.g., `package.json`, `requirements.txt`, `Cargo.toml`, `go.mod`).
4. **Auto-Proceed**: Immediately invoke the QA Engineer (@qa) to begin auditing and debugging the generated codebase.
